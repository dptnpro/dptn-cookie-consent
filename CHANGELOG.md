# Изменения

Формат: раздел `## X.Y.Z` на каждую версию. Текст раздела попадает в описание релиза
на GitHub и в окно «Подробности» обновления в админке WordPress.

## 0.4.0

- Обновления из GitHub Releases: новая версия появляется в «Консоль → Обновления»
  и ставится в один клик, поддерживаются автообновления.
